# Harivansh Tours & Travels Website

A free, single-page responsive website for Harivansh Tours & Travels.

## Files
- `index.html` - website
- `style.css` - styling

## Publish on GitHub Pages
1. Create a GitHub repository named `harivansh-tours`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a free address such as:
   `https://YOURUSERNAME.github.io/harivansh-tours/`

The booking form opens WhatsApp to **+91 7208101104**.

## Images
The first version uses free remote Unsplash images as background images. Replace the image URLs in `style.css` with the business's own vehicle/location photographs whenever available.
